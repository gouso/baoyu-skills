# sketch-notes

Hand-drawn educational style with warm tones and organic feel.

## Design Aesthetic

Friendly sketchnote style that feels like notes from an inspiring lecture. Warm palette with hand-drawn quality throughout. Approachable and educational, making complex topics feel accessible.

## Background

- Color: Warm Off-White (#FDF6E3) with slight paper texture
- Texture: Subtle organic grain, like quality drawing paper

## Typography

### Primary Font (Headlines)

Bold hand-lettered style with natural stroke variation. Marker-pen feel with organic imperfections. Strong weight with slight irregularity.

### Secondary Font (Body)

Casual handwriting style that remains readable. Slight slant, natural spacing, organic feel.

## Color Palette

| Role | Color | Hex | Usage |

## Visual Elements

- Hand-drawn icons and doodles
- Brush stroke underlines and circles
- Arrow connectors (hand-drawn style)
- Thought bubbles and callout boxes
- Sticky-note style highlights
- Sketched charts and diagrams

## Style Rules

### Do

- Allow imperfection in all elements
- Use hand-drawn style consistently
- Layer elements with subtle overlaps
- Keep the friendly, approachable feel
- Use sketched connectors between concepts

### Don't

- Use perfect geometry or sharp edges
- Add digital-looking charts
- Use formal corporate language
- Make elements too precise or uniform

## Best For

Educational content, tutorials, workshops, learning materials, brainstorming, concept explanations
