# blueprint

Technical grid-based style with cool blue tones for architecture and system design.

## Design Aesthetic

Engineering precision with subtle grid overlay. Cool analytical palette that projects technical competence. Clean schematics and dimension-line aesthetics that feel like architectural drawings brought to life.

## Background

- Color: Cool White (#F0F4F8) with subtle blue grid lines
- Texture: Light grid overlay (thin lines, low opacity)

## Typography

### Primary Font (Headlines)

Semi-monospace sans-serif with even character width, engineering aesthetic. Medium weight with precise, technical feel.

### Secondary Font (Body)

Clean monospace-influenced sans-serif. Readable with precise alignment and consistent letter spacing.

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Cool White | #F0F4F8 | Main slide background |
| Grid Lines | Light Blue | #CBD5E1 | Background grid |
| Primary Text | Dark Blue | #1A365D | Headlines |
| Secondary Text | Slate | #475569 | Body text |
| Primary Accent | Cyan | #0EA5E9 | Highlights, key lines |
| Secondary Accent | Teal | #14B8A6 | Secondary elements |
| Diagram Lines | Medium Blue | #3B82F6 | Connectors, flows |

## Visual Elements

- Technical schematics and system diagrams
- Dimension lines with measurement annotations
- Grid-aligned flowcharts
- Node-and-edge network diagrams
- Blueprint-style component layouts

## Style Rules

### Do

- Use precise grid alignment
- Show technical diagrams with dimension lines
- Maintain engineering drawing aesthetics
- Use monospace for data and labels
- Keep visual elements geometric and precise

### Don't

- Use organic or hand-drawn elements
- Add decorative flourishes
- Use warm colors or earth tones
- Crowd slides beyond technical clarity

## Best For

Architecture diagrams, system design, technical documentation, data analysis, engineering presentations
